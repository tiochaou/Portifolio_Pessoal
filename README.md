# Portifolio_Pessoal
Desenvolvimento de um portifólio pessoal básico em HTML.

💻 PORTFÓLIO WEB - GIOVANNI ALLEVI 🚀

📌 Sobre o Projeto

Este é um projeto de Portfólio Pessoal desenvolvido em HTML5, demonstrando a trajetória de aprendizado de Giovanni Allevi como aluno do curso de Desenvolvimento de Sistemas no SENAI.

O objetivo principal da atividade é praticar a estruturação semântica em HTML, manipulação de tabelas, formulários de contato e integração de estilos básicos de apresentação.

🗂️ Estrutura da Página

A página do portfólio é dividida nas seguintes seções:

🏠 Cabeçalho e Navegação: Menu com links âncora para navegação rápida (#sobre, #projetos, #contato).

👤 Sobre Mim: Foto de perfil, resumo sobre a formação no SENAI e lista de habilidades técnicas.

📊 Meus Projetos: Tabela organizada contendo o nome dos projetos, tecnologias utilizadas, status atual e links.
